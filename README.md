# Insurance-Claims-Analytics-Dashboard-using-Power-BI
Interactive Insurance Claims Analytics Dashboard built using Power BI to analyze policy performance, premium collection, claim status, and customer demographics. Implemented Power Query, DAX, Drill-through, Row-Level Security (RLS), and Power BI Service for secure, interactive, and data-driven business reporting.

## Dashboard Overview

This project is an interactive Insurance Claims Analytics Dashboard built using Power BI to analyze insurance policy performance, premium collection, claim amounts, claim status, and customer demographics. The dashboard enables users to monitor key insurance metrics through interactive visualizations, drill-through analysis, and secure role-based access.

## Business Problem

Insurance companies manage thousands of policies and claims every day. Analyzing policy performance, premium collection, claim amounts, claim status, and customer demographics from raw data is time-consuming and difficult. Management requires a centralized dashboard to monitor KPIs, identify claim patterns, evaluate policy performance, and support faster, data-driven business decisions while ensuring secure data access for different users.

## Objectives
Analyze insurance policy performance.
Monitor Premium, Coverage, and Claim Amounts.
Track Active and Inactive policies.
Analyze claims by status and age group.
Compare Premium Amount across Policy Types.
Enable detailed record analysis using Drill-through.
Implement secure role-based access using Row-Level Security (RLS).
Build an interactive dashboard for business users.

Drill-through Analysis

Implemented Drill-through to allow users to navigate from summary visuals to detailed policy and claim information, enabling deeper investigation without creating multiple dashboards.

Row-Level Security (RLS)

Implemented Row-Level Security to restrict data visibility based on user roles.

Configured and tested roles in Power BI Desktop and validated secure access after publishing the report to Power BI Service.

## Key Business Insights
Travel policies generated the highest premium amount.
Active policies significantly outnumber inactive policies.
Rejected claims were higher than settled and pending claims.
Adults contributed the highest claim amount among all age groups.
Interactive filtering allows quick analysis across policies, claims, and customers.
